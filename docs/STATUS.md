# Last Take — оптимизированный Web-прототип Godot

Дата: 2026-11-14. Основная платформа остаётся Windows.

## Активная Web-задача
- Пользователь разрешил следующий шаг после аудита: сохранить старый эксперимент; один репозиторий/общие данные; сначала проверить небольшой оптимизированный Godot-срез; PlayCanvas — условная альтернатива при непрохождении бюджета.
- Ветка `work/web-prototype`, основана на `8b4dd66a4e20a6eed35e4418b9443da5d556d7e4` из Windows preview. Историческая `work/audio-bank-web` не меняется, её публикация/PR #4 не приняты.
- `Source/` не изменён. Зафиксирован tree `6e99b9e957fdd501cbed1c296ab851fd4b2398e5`; банк SHA-256 `8bad99372f4a6edcbfe89870ebcd46796ebb1f58dfed1064782b3c132ba5c60a`, 225 вопросов/23 пользовательских аудио. Доказательство целостности создаётся в builds/web-source-proof.json и входит в CI-диагностику.
- Windows-приёмки всё ещё нет. Постоянный перенос банка/оригинальных медиа в Shared отложен. `Shared/rules.json`, `scenarios.json` и общий исполнитель проверок добавлены без второй редактируемой копии банка.
- `Web/build.py` собирает временный проект из существующего Source, с проверяемыми вставками адаптера. Банк, выборка и переходы ответов/жизней остаются из оригинального GDScript; Web не переписывается в другую игру. Карточки и текстовые слайды рисуются из JSON на текстурах в прежних 3D-позициях.
- Производные GLB создаёт отдельный скрипт Blender 4.3.2 в builds. Сохраняются имена/скелеты/мимические формы. Упрощены второстепенная геометрия, текстуры и процедурные примитивы; неподвижные элементы с общим материалом объединяются. Свет для Web использует поддерживаемые функции Compatibility, основную тень и бюджет 720p, без MSAA/дорогих GI. Исходные модели/Windows не перезаписываются.
- Речь вопросов, изображения и фрагменты вынесены из PCK. HTTP-загрузчик проверяет размер/SHA-256, использует имена по хешу, загружает только текущий и следующие два вопроса; ожидание/ошибка/повтор не меняют жизни, таймер и ID. Тайм-аут готовности сцены начинается после получения стартового пакета.

## Локальные результаты перед CI
- Godot 4.5.1: исходный Source импортирован, все шесть исходных QA-маркеров прошли (500 сеансов, 225 вопросов, 564 карточки, 23 аудио); Source остаётся неизменён. Прежняя диагностика выхода — ObjectDB и 4 ресурса.
- Общие событийные сценарии исполнены на фактическом Windows-коде: речь/пауза, три ошибки, тайм-аут, ошибка последнего вопроса с оставшимися жизнями.
- На адаптированном Godot прошли те же сценарии плюс настоящие HTTP 404/повтор, заморозка времени/жизней, сохранение ID, изображение, пользовательское MP3, пауза/остановка аудио. Найденная гонка старой предзагрузки при перезапуске исправлена; журналы проверяются на SCRIPT ERROR после финального маркера тоже.
- Успешные импорт/экспорт и проверка PCK: 199 записей вместо 2438 в прежнем Web; все размеры/MD5 проверены. Стартовые файлы около 27,4 МБ; PCK около 17,2 МБ, Wasm gzip около 9,8 МБ. Внешние медиа всего банка 21,3 МБ (305 ссылок/ресурсов); они не скачиваются целиком. Точные числа окончательного CI будут в BUILD-INFO.json.
- Нативный импорт с основным Compatibility воспроизводимо падал на завершении в Godot 4.5.1. В staging сохранён native Forward+, а Compatibility задан через .web; последующие чистые импорт/экспорт успешны. Это не изменение Windows-оригинала и не основание обновлять движок.
- Реальный браузерный запуск/GPU/FPS/слышимость и Pages ещё не подтверждены. Настройка Pages недоступна подключённому GitHub API; облачный браузер показывает страницу Settings без входа. Сначала проверить фактический Pages job; технический блокер фиксировать конкретно.

## Проверка и доставка
- Добавлен `.github/workflows/web-prototype.yml`: закреплённые Godot/Blender → исходный QA → общий контракт → временный Web-проект/HTTP QA → аудит пакета → тестовый GitHub Release → Pages. Windows workflow проверяет target и пропускает EXE для Web.
- Статус: реализация и локальные проверки завершены; проверяются CI и тестовое размещение. Поддержка Web не объявлена. После появления ссылки — «ждёт проверки Дмитрия» конкретного source/URL, без merge и стабильного выпуска.
- Бюджет: меню ≤3 МБ, первый играбельный вопрос ≤30 МБ, ориентир ≥30 FPS в 720p на выбранном компьютере, полный сеанс без остановок/потери звука и правил. Требуются реальные замеры. Отсутствие GPU в среде агента не является провалом Godot по FPS.
