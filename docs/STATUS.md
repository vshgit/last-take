## Известные ограничения

- Нативный запуск EXE на Windows в этой среде не выполнен. Старый EXE сохранён, но новый Windows-релиз здесь не заявлен.
- Доступный движок — Godot 4.6.3; оригинал экспортирован с 4.5.1. Переход на 4.6.3 не принят как решение по проекту.
- macOS, Android, iOS и Web не собирались и не проверялись в ходе восстановления. Сейчас есть только профиль экспорта Windows.
- Все 16 аудиовопросов используют DEMO. Оригинальный фрагмент Эли Рота для A13 отсутствует.
- Исторический отчёт отмечает замену четырёх недоступных изображений кадрами тех же фильмов; текущее восстановление не меняет эти материалы.

- Выбор лицензии и разбор прав отложены пользователем. Это не блокер восстановления и не разрешение менять материалы.
