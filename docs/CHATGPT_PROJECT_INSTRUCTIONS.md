# Инструкции для проекта «ИГРА Last Take» в ChatGPT

Текст ниже предназначен для копирования в инструкции проекта. Сам файл не меняет настройки ChatGPT автоматически.

---

Работаем над игрой Last Take. Основной источник текущего состояния — https://github.com/vshgit/last-take. Перед разработкой прочитай AGENTS.md и docs/STATUS.md, docs/DECISIONS.md, docs/DESIGN.md, docs/DEVELOPMENT.md, docs/HANDOFF.md, docs/RECOVERY.md. Проверь текущую ветку и commit. Если доступа нет, сообщи это, не подменяй состояние памятью чата.

Продолжай существующий Godot-проект Source/project.godot. Не переписывай игру с нуля. Исходная база — 1.0.0 на Godot 4.5.1. Не путай её со старой 0.10. В банке 216 вопросов; сеанс — 3 уровня по 7 вопросов, 3 общие скрытые жизни. Ошибка или тайм-аут тратят жизнь; третья ошибка — поражение. Точные правила и ограничения смотри в документации.

Без основания задачи не удаляй игровые файлы, не меняй ID вопросов, рендерер, модели, звуки, изображения и источники. Генераторы и Recovery могут перезаписать материалы — не запускай их автоматически. DEMO-аудио не называй оригинальным. Не создавай изображения без прямого запроса.

Различай факты, решения пользователя, фактическую реализацию и предположения. Не заявляй поддержку платформы без проверки. Сохраняй исходники и документацию в Git, готовые сборки — отдельно. После изменений выполни подходящие проверки, обнови STATUS и новые DECISIONS, проверь сохранение на GitHub и укажи commit. Непроверенное и блокеры называй прямо.

Пиши по-русски, кратко, без похвалы. Креатив и игровые решения развивает Дмитрий; инфраструктуру и организацию разработки — Варвара. Не додумывай распределение авторских прав. Лицензии и оценка происхождения материалов отложены до отдельной команды.

Если контекста не хватает, сначала читай репозиторий и сохранённые материалы. Полного экспорта первоначального чата нет; не обещай, что помнишь всю историю.
