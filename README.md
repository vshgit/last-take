# Last Take

Хоррор-квиз от первого лица на Godot. Игрок привязан к стулу в подвальной комнате и отвечает на вопросы Киномана о кино: карточками или движениями головы. Креатив и игровые решения развивает Дмитрий; организацию разработки и инфраструктуру — Варвара. Подробные авторские титры пока не согласованы.

## Текущая основа

Восстановленный проект версии **1.0.0** от 6 ноября 2026 года. База содержит 216 вопросов; один сеанс — 3 скрытых уровня по 7 вопросов и 3 общие скрытые жизни. Это существующий Windows-прототип, а не подтверждённый выпуск для всех платформ.

Основной проект: **`Source/project.godot`**. Исходная версия движка — **Godot 4.5.1**; результаты повторной проверки на доступном 4.6.3 записаны в `docs/STATUS.md`. Рендерер Forward+ сохранён.

## Быстрый старт разработчика

1. Клонировать этот репозиторий.
2. Прочитать `AGENTS.md`, затем `docs/STATUS.md` и `docs/HANDOFF.md`.
3. Открыть `Source/project.godot` в Godot и дождаться завершения импорта.
4. Запустить игру из редактора. Команды автоматической проверки и экспорта — в `docs/DEVELOPMENT.md`.

## Структура

| Путь | Назначение |
| --- | --- |
| `Source/` | Код GDScript, сцены, шейдеры, данные и все готовые игровые ассеты |
| `ArtSource/` | Редактируемая модель Blender, исходные модели, звуки и референсы |
| `References/` | Найденные документы с вопросами, изображения и пакеты DEMO |
| `Recovery/` | Три исторических файла восстановления; автоматически не запускать |
| `Лицензии/` | Исходные сведения об источниках материалов, сохранены без изменений |
| `QA/`, `QA.txt` | Исторические результаты проверок от 6 ноября, не новый отчёт |
| `docs/` | Текущий статус, решения, устройство проекта, инструкции и контрольные суммы |
| `tools/verify_recovery.py` | Проверка сохранности восстановленных файлов и игровых данных |

## Сборки и материалы

EXE со встроенными ресурсами сохранён в исходном архиве `LastTake-Windows-v1.0.zip`, отдельно от истории исходников. `Launch-Compatibility.cmd` из архива также сохранён, но работает только рядом с соответствующим EXE. Новые проверенные сборки предполагается хранить в GitHub Releases.

Все 16 аудиофрагментов вопросов в текущей версии — **DEMO**, включая A13; они не являются оригинальными голосами актёров. Замена материалов и выбор лицензии отложены по решению пользователя. Существующие сведения об источниках не удалялись. Публичность репозитория не означает предоставления какой-либо единой лицензии на все вложенные материалы.
