# Изолированный Web-прототип

`Source/` и Windows preview не изменяются. `Web/build.py` создаёт временную копию Godot-проекта в `builds/web-source/`, применяет проверяемые адаптации и экспортирует `builds/web-dist/`. Файлы карточек/текстовых слайдов не включаются; их текст берётся из единственного `Source/content.json`. Вопросные изображения, речь и аудиофрагменты публикуются отдельно и запрашиваются для текущего и двух следующих вопросов.

Оригиналы не переносятся до приёмки Windows. `Shared/` пока содержит контракт и общие проверочные сценарии, а не вторую редактируемую копию банка. Web-ветка основана на Windows preview, что не означает её приёмку или merge в main.

Сборка: `python3 Web/build.py --godot /path/to/Godot_v4.5.1-stable_linux.x86_64`. Нужны соответствующие Web export templates, Blender 4.3 и Pillow. В CI установлены закреплённые версии движка/шаблонов; производные GLB генерируются только в builds. Никакие Recovery/старые генераторы не запускаются.

Качество упрощённых моделей и света требует ручного сравнения. Показатели программного GPU облачного браузера не характеризуют компьютер пользователя. Прототип не является принятым браузерным портом.
